# 柳之卦 v1.6.0

## 中文

- 右上角新增可点击的“六爻 / 塔罗”占卜方式选择。
- 新增完整 78 张塔罗牌与“缘起 / 此刻 / 趋向”三牌阵，包含正逆位、本地解牌、备注、固定与独立历史。
- 主页中央“卦 / 牌”印章可拖动，松手后会缓慢柔和地归于正中。
- 铜钱动画新增“星轨回旋”，保留经典浮动与物理飞出。
- 开屏演示结束后回到原设置页面，并保留未保存的开屏样式与进度草稿。
- 塔罗全流程离线运行，与六爻结果和历史相互独立。

## English

- Added a tappable Liuyao / Tarot mode selector.
- Added a complete 78-card Tarot deck and an Origin / Present / Direction spread with upright/reversed meanings, offline readings, notes, pins, and separate history.
- Made the central Liuyao and Tarot seals draggable with a slow, gentle return to center.
- Added the Orbital Spiral coin animation alongside Classic Float and Physics Launch.
- Boot Preview now returns to the same Settings layer while preserving unsaved draft choices.
- Tarot runs fully offline and remains independent from Liuyao results and history.

## APK

- Standard: Android 8.0+ (API 26+)
- Legacy: Android 6.0+ (API 23+)

Both APKs use the established long-term Ryu's Gua v1 signing certificate.
