# 柳之卦 v1.5.0 · 结果页与开屏优化

v1.5.0 聚焦起卦完成后的信息层级、设置中心流畅度，以及七套开屏样式的进度一致性；不改变既有起卦、六爻排盘、离线解卦、历史或 AI 数据逻辑。

## 卦象结果页

结果页由原来的七个等权按钮收敛为：

- 顶部：设置、历史
- 主操作：查看解卦
- 收卦操作：此卦已成 · 再起一卦

“经文”和“排盘”移入离线解卦页。用户先查看卦象，再进入解卦；需要核对原文或盘面时，可在解卦页继续打开经文与排盘。

“此卦已成 · 再起一卦”保持四字·四字文案节奏。该按钮返回主页，不会绕过正式起卦的五分钟节制规则。

## 设置中心

设置弹窗不再叠加容易卡顿的系统窗口过渡，改用 110 ms 的硬件图层淡入，减少首次打开复杂设置时的停顿感。

设置项继续遵循四字标题与简短说明的既有文案体系。

## 七套开屏进度

“开屏进度”开关现在对全部七套样式生效：

1. 经典初版：既有金色加载条
2. 电子法器：法器启用进度
3. 古意极简：静候卦成进度
4. 周易原典：易序推演进度
5. 卜筮仪式：正心持念进度
6. 终端自检：系统自检进度
7. 六爻序列：六爻列阵进度

关闭“开屏进度”后，各样式仍保留原有分步文字与仪式动画，但不显示额外进度条。

## 开屏演示

交互设置新增四字按钮“开屏演示”：

- 使用设置面板中当前选择的开屏样式
- 同步使用当前“开屏进度”开关状态
- 全屏播放一次
- 不保存尚未确认的草稿设置
- 演示完成后恢复原有已保存配置

## 不变内容

- 离线优先、AI 可选增强
- Standard / Legacy 双 APK
- Android 包名 com.ryusgua.app
- 本地《周易》经文与六爻排盘
- v1 长期正式签名身份
