# 柳之卦 v1.6.0 设计与验收说明

## 双占卜入口

主页右上角以可点击的“六爻”或“塔罗”替代旧静态“易”字。点击后进入模式选择页；当前模式会保存在本机，下次启动继续使用。切换模式只改变当前占卜流程，不会互相改写历史记录或计算结果。

## 塔罗占卜方案

- 牌组：完整 78 张，包括 22 张大阿尔卡那和 56 张小阿尔卡那。
- 牌阵：三牌横排，位置依次为“缘起 / 此刻 / 趋向”。
- 抽取：一次洗牌后取三张不重复牌，每张独立决定正位或逆位。
- 呈现：三张牌按节奏逐张显现；画面使用深绿底、米白线框、朱红强调色与终端式小字，不额外引入写实牌面素材。
- 解牌：先显示每张牌在对应位置的正逆位含义，再生成三牌合参。所有牌义与组合均由本地数据生成，无网络也可使用。
- 历史：塔罗使用独立历史存储，保留最近 30 条未固定记录，固定记录不受上限影响；支持备注与固定。
- 边界：塔罗内容定位为文化体验与自我观察，不表述为确定未来的结论；不会调用或重算六爻卦象。

## 动画与触控

- 中央“卦”印章及其方框可以拖动，移动范围限制在安全画布内；松手后使用约 1.45 秒的缓出曲线回到精确中心。
- 塔罗主页的“牌”印章复用同一拖动与归中逻辑。
- 铜钱动画新增“星轨回旋”：三枚铜钱沿相位错开的椭圆轨迹旋转，轨道半径逐渐衰减，最终平滑收束到落定位置。
- 原“经典浮动”和“物理飞出”完整保留，设置中的动画选择扩展为三项。

## 开屏演示

在“设置 → 交互与动画”中点击“开屏演示”后，设置弹窗只暂时隐藏。演示结束会恢复原设置层，样式、进度等尚未保存的草稿值保持不变。

## 验收清单

- 六爻主页右上角显示“六爻”，可进入模式选择页并切换塔罗。
- 塔罗可完成三张不重复牌的正逆位抽取、结果查看、解牌复制及历史回看。
- 六爻和塔罗历史互相独立，清理当前历史不会误删另一模式。
- 中央印章可拖动；松手后缓慢回正，回正过程中可再次抓取。
- 三种铜钱动画均可完成六爻起卦，取消起卦后不残留动画。
- 任意开屏样式演示结束后仍停留在交互设置页面，未保存选择不丢失。
- Standard（API 26+）与 Legacy（API 23+）均可编译安装。

# Ryu's Gua v1.6.0 Design & Acceptance Notes

Version 1.6.0 adds a persistent Liuyao / Tarot selector, a fully local 78-card three-position Tarot spread, draggable center seals with a gentle return animation, a third Orbital Spiral coin animation, and a Boot Preview flow that returns to the same unsaved Settings draft. Tarot records are isolated from Liuyao history, and all Tarot meanings are available offline.
