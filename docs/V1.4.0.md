# 柳之卦 v1.4.0 · 本地六爻排盘

v1.4.0 在既有三钱六爻、本卦/之卦、完整《周易》卦辞爻辞与离线解卦之上，新增 Java 原生、完全离线的六爻纳甲排盘层。

## 新增

- 八宫、宫五行、本宫/一至五世/游魂/归魂
- 世爻、应爻
- 京房纳甲天干地支
- 六亲、六神
- 自动按起卦时间计算月建与日干支，并据此取旬空
- 旺相休囚死、十二长生
- 临月、临日、月破、日破、暗动、旬空与真空
- 动爻变支、化进神、化退神、回头生、回头克
- 月墓、日墓、动爻墓、化墓与空墓提示
- 三合实局/虚合提示、六合卦、六冲卦
- 卦变生克、反吟与伏吟提示
- 可选父母/兄弟/子孙/妻财/官鬼为用神，并标记元神、忌神、仇神及基础有力/无力状态
- 11 专题完全离线术理索引：装卦排盘、用神取用、旺衰月日、动静空破、进退神化、三合六合、墓库论法、断卦步骤、四神有力、卦变反伏、卦象判辞
- 结果页新增「排盘」，支持复制完整盘面与打开术理索引
- 离线解卦追加当前六爻盘面摘要；可选 AI 解卦会同时使用盘面事实与当前相关的本地术理摘要

## 数据与授权

《周易》卦辞与爻辞继续复用柳之卦既有 `zhouyi.json`，没有重复引入另一份经文。

六爻规则与静态表参考并重新实现自 `Johnson-Jia/liuyao-divination`，该项目采用 MIT License；版权及许可证全文已保留在 `THIRD_PARTY_NOTICES.md`。

不同六爻流派在部分细则上可能存在不同取法，因此排盘页会展示可核验的盘面事实，术理索引用于传统文化阅读与规则说明，不宣称某一流派为唯一标准。
