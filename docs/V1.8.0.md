# 柳之卦 v1.8.0 设计与验收说明

## 占问内容

- 六爻与塔罗主页的题头区域可点击写下最多 120 字占问，也可完全留空。
- 占问随本局历史保存在应用私有存储中；旧历史缺少 `question` 字段时按空值读取。
- 占问不会因调用离线解读而离开设备。用户主动调用 AI 时，占问才与本局既定卦象或牌阵一同发送至其配置的服务商。
- 从结果开始下一局或切换占卜体系时清空当前占问；取消正在进行的占卜时保留，方便重新开始。

## AI 分层与长度

- 六爻系统提示只处理《周易》卦义、动爻、之卦、纳甲盘面与用神约束。
- 塔罗系统提示只处理既定牌阵、正逆位、牌位关系、牌间呼应与行动建议。
- 两套提示均禁止重新起卦/抽牌、绝对预言、泄露内部思考过程及替代高风险专业判断。
- 正文建议长度为 700–1000 个中文字符，信息确有需要时最多 1200 个字符；Chat Completions 和 Responses 的输出预算相应放宽。

## 塔罗离线合参

- 单牌：聚焦牌面主题、正逆位状态与一个可执行行动。
- 三牌：把三个牌位组织成变化线，明确趋向只是当前惯性而非固定结果。
- 四象：对照行动、感受、思考与现实承载，寻找最不协调的一象。
- 多牌阵共同分析大阿卡那比例、主导花色、正逆位结构和牌位间支持/牵制关系。

## 结构、无障碍与小屏

- `MainActivity.java` 只承担 Activity 生命周期、沉浸式窗口、音频释放与摇动传感器。
- 自绘与触控移至 `GuaView.java`；AI 提示词、塔罗合参、无障碍节点分别位于独立组件。
- Canvas 控件通过虚拟 AccessibilityNode 暴露给 TalkBack / Switch Access；关键按钮使用至少 48dp 的语义与命中范围。
- 主屏标题、卦象结果和起卦面板在紧凑高度设备上使用独立布局；字体跟随系统缩放，最高按 1.18 倍受控适配，长文行距同步增长。

## 验收

- 留空和写入占问均可完成六爻、塔罗全流程，历史升级后旧记录不丢失。
- 六爻 AI 请求不得包含塔罗系统身份；塔罗 AI 请求不得包含《周易》系统身份。
- 一牌、三牌和四象离线合参均生成与各自结构相符的综合段落。
- TalkBack 可聚焦并触发主页、结果、离线解读、AI、历史等主要操作。
- 320dp 宽或紧凑高度设备不出现主要按钮、卦象堆栈或牌阵越界。
- Standard / Legacy 两个变体均通过 Android 构建。
