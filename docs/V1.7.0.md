# 柳之卦 v1.7.0 设计与验收说明

## 目标

v1.7.0 不把塔罗继续塞进六爻界面，而是让两套占卜体系共享开屏、声音、触感与模式入口，同时各自拥有牌阵/投币动画、内容索引和解读流程。

## 塔罗流程

- 主页可选“一牌照见”“三牌成阵”“四象观局”。三种牌阵分别使用 1、3、4 张互不重复的牌。
- 78 张牌、正逆位牌义、行动建议、牌阵位置与七篇本地索引全部读取自 `tarot_cards.json`。
- 结果页进入“离线解牌”后，可继续打开“牌义”查看每张牌的关键词、完整方向性解释、牌位作用和建议。
- AI 解牌是可选增强层；提示词只包含本局已经抽定的牌、正逆位、牌位和本地牌义，禁止模型重新抽牌或声称确定未来。
- 塔罗历史保存牌阵 ID、任意支持的牌数、备注、固定状态、AI 解牌与模型；v1.6.0 的三牌记录按默认三牌阵继续读取。

## 交互与视觉

- 主页中央印章被拖动时只旋转外框，中心文字保持端正；松手后外框伴随印章缓缓归中。
- 右上角六爻 / 塔罗入口为无边框文字按钮，保留清晰点击区域与下划提示。
- 经典浮动增加呼吸波纹、落点光点和基线反馈；星轨回旋增加多层椭圆轨道、七段拖尾并延长至约 1.68 秒。
- 塔罗牌面增加双层边框、花色/大牌标识、几何核心纹样、牌名与正逆位层级；翻牌提供依次翻牌、流光显影、轻叠展开三种样式。

## 模式分层

- 共享设置：开屏样式与进度、动效总开关、声音、触感、摇动。
- 六爻专属：经典浮动 / 物理飞出 / 星轨回旋、垂直翻转、手动逐爻、十一专题六爻术理索引。
- 塔罗专属：三种翻牌样式、七篇牌系与牌阵索引；不显示铜钱和逐爻选项。

## 验收要点

- 三种牌阵均可完成抽牌、离线解牌、牌义、复制、历史回看与 AI 解牌。
- 切换占卜方式后，设置中心与索引标题/内容立即与当前体系一致。
- 关闭动效后塔罗快速完成，不继续播放翻牌序列。
- JSON 恰含 78 个唯一 ID，牌阵为 1 / 3 / 4 张；旧三牌历史不丢失。
- Standard（API 26+）与 Legacy（API 23+）均通过 Debug 构建。
